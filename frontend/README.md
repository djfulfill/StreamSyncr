# StreamSync Frontend

Unified streaming tracker dashboard built with React + Vite + Tailwind CSS.

## Features

- Connect WeTrakr, Trakt, TMDB services
- Unified library view with grid/list modes
- Search across all services
- Cross-platform sync engine
- Movie/show detail pages with TMDB metadata
- Watch providers and cast info

## Run

```bash
npm install
npm run dev    # http://localhost:3030
```

## Build

```bash
npm run build  # outputs to dist/
```
